# 流程控制语句：通过一些语句，控制程序的执行流程

## 1.顺序结构：从上往下依次执行，是程序默认的执行过程


## 2.分支结构

### if：根据条件选择

#### 第一种：单个
①语法格式
	 
	 if(关系表达式)
	   {
		 语句体
	   }

②执行流程：先执行小括号里的关系表达式，如果条件成立，就执行大括号里的语句；反之则不执行
   
定义变量`int a = 20;`

判断

	if (a > 10)
	{
		printf("真的大于10");
	}

③使用场景：如果要对一些参数来进行判断，根据判断的结果去执行不同的代码

④`细节1`：在c语言当中，如果判断的结果是一个数字，`非0`表示条件成立，`0`表示结果不成立
	
	if (0)
	{
		printf("执行了");
	}//没有执行
 `细节2`：如果大括号里面的语句体只有一行，那么大括号可以省略不写（了解）
	
	int b = 20;
	if (b > 10)
		printf("真的大于10\n");

#### 第二种：两个
语法格式：
	 
	 if (关系表达式)
	 {
		 语句体A;
	 }
	 else
	 {
		 语句体B;
	 }
	

#### 第三种：多个 
语法格式
	
	if (关系表达式A)
	{
		语句体A;
	}
	else if (关系表达式B)
	{
		语句体B;
	}
	else if (关系表达式C)
	{
		语句体C;
	}
	…………
	else
	{
		语句体N;
	}
	

> `注意`：if可嵌套




### switch：把所有的选择一一列举出来，根据不同的条件任选其一
语法格式：
	
	switch (表达式) {
	case 值1:
		语句体1;
		break;
	case 值2;
		语句体2;
		break;
	………………
	default:
		语句体n;
		break;
	 }
	 
#### *运行流程*：

1.根据小括号中表达的结果去匹配对应的case
	 
2.执行对应case里面的代码
	 
3.如果在执行的过程中遇到`break`，那么直接结束整个switch语句

#### *细节说明*：

> ①：表达式：计算结果只能为（字符/整数）

> ②：case：值只能是（字符/整数）的字面量，不能是变量

> ③：case：值不允许重复

> ④：break：表示中断，结束的意思，结束switch语句

> ⑤：default：所有情况都不匹配，执行该处的内容

> ⑥：default：可以写在任意位置，甚至可以省略不写*/


## if的第三种格式和switch各自的使用场景：
	 
if：一般是对`一个范围`进行判断，从上往下依次执行

switch：`有限个`case进行匹配的情况，10个左右，直接匹配，**提高执行效率**

### case穿透:

如果没有遇到break，就会继续执行下面的case，直到遇到break，或者执行整个switch代码

`细节`：case穿透只会往下穿，不会回到上面
	
	int num = 1;
	switch (num)
	{
	default:
		printf("当前数字为其他\n");

		printf("数字为1\n");
		//break;

		printf("数字为2\n");

**当代码有多个重复时可以用case穿透来简化代码**

## 定义函数的终极绝招
     
三个问题：
	 
1.我定义函数，是为了干什么？  `函数体`

2.我干了这件事情，需要什么才能完成  `形参`

3.我干完了，调用处是否需要继续使用  `返回值类型`

需要继续使用   `必须写`
								  
不需要    `void`   

## 注意事项：
	
> 1.函数不调用就不执行

> 2.函数名不能重复

> 3.函数与函数之间是平级关系，不能嵌套定义

> 4.自定义函数写在main函数的下面，需要在上方声明：返回值类型 函数名（形参1，形参2…）

> 5.return下面不能编写代码，永远执行不到，属于无效的代码

> 6.函数的返回值类型为void，表示没有返回值，return可以省略不写,
	   如果书写了return，后面不能跟具体数据，仅表示结束函数

# 根据大佬的要求，接下来展示函数的解题
## 1.
 **使用全局变量并实现一个函数，用于获取一组数的和，最大值与最小值**
 
 **输入：第一行一个整数 n，第二行 n 个整数。**
 
 **输出：和、最大值与最小值，用空格隔开**

解：
```c
#include <stdio.h>

/*全局变量：用于存放三个结果*/
int sum = 0;   /* 和 */
int max = 0;   /* 最大值 */
int min = 0;   /* 最小值 */
```
写在所有函数*外面*的变量是全局变量，`main` 和`其他函数`都能直接读、直接改。所以函数不需要"把结果返回"——它改完全局变量，main 里立刻就能看到新值。

这里写 `= 0` 只是求个心安：全局变量本来就会被自动初始化为 0。真正决定结果的，是下面那句 `sum = x; max = x; min = x;`。


```c
/*函数：读入剩下的 n 个数，并统计和、最大值、最小值*/
void all(int n)
{
    int i;
    int x;              /* 只用一个普通变量，读一个、比一个、丢掉一个 */

    /* 先读入第 1 个数，让它当三个结果的起点 */
    scanf("%d", &x);
    sum = x;
    max = x;
    min = x;
```
这是整个写法的精髓，读一个数就用掉一个，用完立刻丢弃，`x `这个变量反复被覆盖。
```c
    /* 再依次读入剩下的 n-1 个数 */
    for (i = 1; i < n; i++) {
        scanf("%d", &x);

        sum += x;                              
        if (x > max) max = x;                  
        if (x < min) min = x;                 
    }
}
```
注意这里 `i` 是**从 1 开始**的，因为第 1 个数已经在循环外读掉了，循环里还要读 `n - 1` 个，所以 i 走 `1, 2, ..., n-1`，一共 `n-1` 轮，加起来正好 n 个。**如果写成 i = 0; i < n，就会多读一个数（读到下一组测试数据去了），或者少算一个数。**

`sum += x;` 是 `sum = sum + x;` 的简写，意思是"把刚读到的 `x` 累加进去"。

两个 if 是"打擂台"：当前这个数比擂主 max 大，就让它当新的最大值；比 min 小，就让它当新的最小值。两个都要检查（一个数不可能同时创下最大和最小纪录，所以两个 if 互不干扰）。
```c
int main()
{
    int n;
    scanf("%d\n",n)        /*输入n*/
    all(n);                /* 调用函数*/
    
    /* 输出：和、最大值、最小值*/
    printf("%d %d %d\n", sum, max, min);

    return 0;
}
```
接下来正常走就行

**这种一一替换的函数可以不用指针来解循环题😎（我做这道题时还没学指针…………**
